# Synthetic Seed Data Instructions

Use `donor_thank_you_synthetic_seed_data.json` as the source dataset for the Prisma seed script.

## Dataset

- 25 synthetic donors
- 50 synthetic donations
- Matched donors
- First-time donors
- Repeat donors
- Major donors
- Recurring donors
- Lapsed-returning donors
- Anonymous donations
- No-match donations
- Uncertain match-style donations

## Email Testing

All donor emails use controlled Gmail plus-address aliases, for example:

```text
prasadkanchar2004+maya.sharma@gmail.com
prasadkanchar2004+nomatch.noah@gmail.com
```

These are safe for later Gmail draft/send testing because they can route to the same mailbox.

## Copilot Prompt

```text
Create a JavaScript Prisma seed script for the Donor Thank-You Automation backend.

Use this dataset file:
donor_thank_you_synthetic_seed_data.json

Important:
- Use JavaScript only.
- Do not use TypeScript.
- Do not modify the Prisma schema.
- The database already exists in Supabase PostgreSQL.
- Prisma introspection is already complete.
- Tables are donors, donations, drafts, email_logs, audit_logs.
- The dataset contains synthetic data only.
- Emails use controlled Gmail plus-address aliases for safe future email draft/send testing.

Create:
server/prisma/seed.js

Seed behavior:
1. Import PrismaClient.
2. Load the JSON dataset.
3. In development only, clear records in this order:
   email_logs, drafts, donations, donors, audit_logs.
4. Insert donors first.
5. Create a donorCodeToId map from donor_code to inserted donor id.
6. Insert donations.
7. For matched donations, connect donor_id using donor_code.
8. For no-match/anonymous/uncertain donations where donor_code is null, keep donor_id null.
9. Insert audit log action synthetic_dataset_seeded.
10. Print clear console output:
   - donors inserted
   - donations inserted
   - no-match donations inserted
   - seed completed

Important DB mapping:
- Do not manually insert id.
- Do not manually insert full_name if it is generated by the database.
- Do not manually insert created_at or updated_at unless needed.
- Insert campaign_history and tags as text arrays.
- Insert personalization/risk JSON only later in drafts, not in this seed.

Add package.json script:
"seed": "node prisma/seed.js"

After implementation, I should be able to run:
cd server
npm run seed
```
